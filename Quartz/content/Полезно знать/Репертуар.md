Репертуаром персонажа называется его память магических заклинаний
Обычный источник репертуара персонажа это его память.
По умолчанию максимальный размер памяти  персонажа равен 1

Персонаж может сотворять только те заклинания, которые есть у него в репертуаре.

Если персонаж держит в руках магический свиток, заклинание на этом свитке считается в репертуаре персонажа

Для того чтобы поместить заклинание в память персонажу необходимо уничтожить носитель на котором содержится это заклинание
Персонаж может выбросить заклинание из памяти, в таком случае оно будет уничтожено
