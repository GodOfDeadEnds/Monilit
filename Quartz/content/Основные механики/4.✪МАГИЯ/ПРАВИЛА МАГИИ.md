# МАГИЯ

### РЕПЕРТУАР

Репертуар это количество заклинаний которое персонаж может запомнить. На старте это одно заклинание. С развитием персонажа репертуар расширяется за трату опыта персонажа.

При произнесении заклинаний всегда есть риск потерять их из репертуара.

  

### ОПИСАНИЕ ЗАКЛИНАНИЙ

Сотворения заклинаний из репертуара заклинателя совершается основным действием.

Эффект заклинаний начинает действовать в конце раунда действующий стороны боя.

## ВНЕДРИТЬ В ПРАВИЛА

Для того чтобы сотворить заклинание определенного ранга, то нужно потратить самоцветов МАГИИ не меньше ранга заклинаний. Заклинания нулевого ранга всегда сотворяются успешно но если хотите можете использовать самоцветы магии.

  
  
  

## 🗲СОТВОРЕНИЕ ЗАКЛИНАНИЯ

ОСНОВНОЕ ДЕЙСТВИЕ 

Брось один или несколько самоцветов [[⬢]]МАГИИ. 

Заклинание произнесено успешно если хотя бы один из брошенных дайсов больше или равен сложности. 

СЛОЖНОСТЬ: 10+ранг заклинания

УСПЕХ: [[⬢]]МАГИИ. его сотворившая не тратится.

ПРОВАЛ: [[⬢]]МАГИИ. потрачена.

МИН: Заклинание стирается из активного репертуара.

МАКС: Все потраченные [[⬢]]МАГИИ. восстанавливается.
